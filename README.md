# BrandForge

**BrandForge** is a full-stack web platform that connects **brands** and **content creators** through structured campaigns and contests. It enables brands to launch campaigns, creators to participate, and admins to manage the ecosystem efficiently.

## Overview

BrandForge solves the problem of fragmented influencer marketing by providing a **centralized platform** where:

- Brands can create and manage campaigns
- Creators can discover and participate in contests
- Admins can monitor and control the system

---

## Features

### Admin
- Manage users (brands & creators)
- Approve/reject campaigns
- Monitor platform activity
- Declare contest winners

### Brand
- Create campaigns
- Set contest rules and rewards
- View participants
- Select winners

### Creator
- Browse campaigns
- Participate in contests
- Submit entries
- Track results

### Authentication
- JWT-based authentication
- Role-based access control (RBAC)
